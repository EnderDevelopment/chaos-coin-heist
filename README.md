# Chaos Coin Heist

Chaos Coin Heist is a multiplayer simulator game where players collect loot, earn Chaos Coins, raid other players' bases, and survive random disasters. The game features a Robux shop with optional upgrades, rare pets, and leaderboards to compete with other players.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Create a new place.
4. Import the models into their respective locations:
   - IslandModel.rbxm into Workspace
   - BaseModel.rbxm into ServerStorage
   - DisasterModels.rbxm into ServerStorage
   - PetModels.rbxm into ServerStorage
5. Add the scripts to their respective services:
   - CoreGameMechanics.lua into ServerScriptService
   - PlayerScripts.lua into StarterPlayerScripts
   - BaseScripts.lua into ServerScriptService
   - DisasterScripts.lua into ServerScriptService
   - ShopScripts.lua into ServerScriptService
   - LeaderboardScripts.lua into ServerScriptService
6. Import the UI elements into StarterGui:
   - MainUI.rbxl into StarterGui
   - ShopUI.rbxl into StarterGui
   - LeaderboardUI.rbxl into StarterGui

## Use

1. Launch the game in Roblox Studio.
2. Players will spawn on a colorful island with their own base.
3. Collect loot and funny pets to earn Chaos Coins.
4. Raid other players' bases in a protected, limited-risk system.
5. Survive random disasters that hit the map every few minutes.
6. Upgrade your base, unlock new areas, and compete on leaderboards.
7. Purchase optional upgrades from the Robux shop to enhance your gameplay experience.
